# 채소팡

햇살밭의 밭뭉치 친구들과 함께하는 모바일 세로 화면용 3매치 퍼즐입니다.

## 이 저장소

채소팡의 정적 웹 실행 파일을 게시하는 전용 저장소입니다. `mini-puzzle-play`의 말랑 블록과 별도로 관리합니다.

- 50개 스테이지와 단계별 목표
- 채소 캐릭터와 색상별 매치 이펙트
- 특수 블록, 피버, 동행 친구와 친밀도
- 모바일 터치 조작과 로컬 진행 저장

## 게시 설정

GitHub 저장소의 **Settings → Pages → Build and deployment**에서 다음을 선택합니다.

- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/(root)**

게시가 완료되면 `https://cbr1024.github.io/chaesopang/`에서 실행할 수 있습니다. 별도 사용자 정의 GitHub Actions 워크플로는 포함하지 않습니다. GitHub Pages 자체의 내부 게시 작업은 GitHub에서 관리합니다.

## 온라인 랭킹

온라인 랭킹은 Supabase Edge Function과 PostgreSQL에 연결됩니다. 서버가 발급한 게임의 조작 기록을 같은 엔진으로 다시 계산해 점수·별·순위를 확정합니다. 스테이지별 최고점, 주간 랭킹, 가까운 라이벌, 동행 친구의 친밀도와 주간 보상 수령 상태를 서버에 저장합니다.

연결 장애 시 게임은 **연습 플레이**로 실행되고 진행 정보는 기기에 저장됩니다. 서버에서 검증하지 않은 연습 기록은 온라인 랭킹에 등록하지 않습니다. 기존 기기 저장 데이터는 유지합니다.

싱글 플레이에는 가입이 필요하지 않습니다. 랭킹에 참여할 때만 고유 닉네임을 등록하고, 인증 토큰은 기기에 저장합니다. 서버에서 중복 닉네임을 차단합니다. 기기 변경 시 설정의 암호화 백업 파일과 사용자 본인의 복구 암호가 필요합니다. 백업 파일이나 암호를 잃으면 닉네임만으로 기존 계정을 복구할 수 없습니다.

`game-config.js`에는 공개 API 주소와 클라이언트 규칙 식별자만 설정하며, 비밀 키를 넣지 않습니다.

## 공개 파일 범위

실행에 필요한 HTML·CSS·JavaScript·SVG, `.nojekyll`, 이 안내 문서만 포함합니다. 서버 코드, 데이터베이스, 인증 정보와 개발용 테스트는 게시 대상에서 제외합니다.
